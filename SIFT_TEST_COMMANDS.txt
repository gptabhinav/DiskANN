SIFT Dataset Testing Commands for Initialization Strategies
===========================================================

Prerequisites:
- Build the project: cd build && make -j$(nproc)
- Download SIFT dataset (done): wget ftp://ftp.irisa.fr/local/texmex/corpus/sift.tar.gz

Setup Data:
-----------
cd build
mkdir -p data
tar -xf ../sift.tar.gz -C data/

Convert Data:
-------------
./apps/utils/fvecs_to_bin float data/sift/sift_learn.fvecs data/sift/sift_learn.fbin
./apps/utils/fvecs_to_bin float data/sift/sift_query.fvecs data/sift/sift_query.fbin
./apps/utils/compute_groundtruth --data_type float --dist_fn l2 --base_file data/sift/sift_learn.fbin --query_file data/sift/sift_query.fbin --gt_file data/sift/sift_query_learn_gt100 --K 100

Build Indexes:
--------------
# MEDOID strategy (baseline)
./apps/build_memory_index --data_type float --dist_fn l2 --data_path data/sift/sift_learn.fbin --index_path_prefix sift_medoid_index --max_degree 32 --Lbuild 50 --alpha 1.2 --init_strategy medoid

# RANDOM strategies with different numbers of random points
./apps/build_memory_index --data_type float --dist_fn l2 --data_path data/sift/sift_learn.fbin --index_path_prefix sift_random_10 --max_degree 32 --Lbuild 50 --alpha 1.2 --init_strategy random --num_random_init_points 10

./apps/build_memory_index --data_type float --dist_fn l2 --data_path data/sift/sift_learn.fbin --index_path_prefix sift_random_50 --max_degree 32 --Lbuild 50 --alpha 1.2 --init_strategy random --num_random_init_points 50

./apps/build_memory_index --data_type float --dist_fn l2 --data_path data/sift/sift_learn.fbin --index_path_prefix sift_random_100 --max_degree 32 --Lbuild 50 --alpha 1.2 --init_strategy random --num_random_init_points 100

Expected Results Summary:
------------------------
Dataset: SIFT 100K points, 128 dimensions

Build Performance:
- MEDOID: ~16.4s, avg degree 26.09, 1 node deg<2
- RANDOM-10: ~14.1s, avg degree 23.66, 152 nodes deg<2  
- RANDOM-50: ~15.4s, avg degree 25.06, 11 nodes deg<2
- RANDOM-100: ~17.3s, avg degree 25.07, 5 nodes deg<2
- RANDOM-400: ~22.8s, avg degree 24.90, 5 nodes deg<2

Search Performance @ L=100:
- MEDOID: 99.78% recall, ~6,661 QPS
- RANDOM-100: 98.39% recall, ~6,407 QPS  
- RANDOM-400: 99.00% recall, ~6,665 QPS

Graph Connectivity (BFS diameter):
- MEDOID: 7 hops (excellent connectivity)
- RANDOM-10: 11 hops (poor connectivity)
- RANDOM-100: 9 hops (good connectivity)
- RANDOM-400: 9 hops (good connectivity)

Recommendations:
- For high recall: Use MEDOID strategy
- For fast builds: Use RANDOM with 100 points  
- For balanced: Use RANDOM with 100-200 points
